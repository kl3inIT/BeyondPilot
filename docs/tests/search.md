# Search: verification matrix

Boundaries follow [conventions › Testing](../conventions.md#testing). Matching is PostgreSQL's work (the unaccented, weighted vector, prefixes and trigram similarity), so the index is tested against PostgreSQL through its repository. The index is fed by events after an operator's commit, so the whole path starts the full application, changes a program over real HTTP and waits for the result a visitor reads without a session.

| Contract                                                                                                                                                                                                                                                                            | Regression it catches                                                            | Test                                                                                                           |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Text is found with or without its Vietnamese marks, `đ` included                                                                                                                                                                                                                    | "doi moi" not finding "Đổi mới"                                                  | `SearchDocumentRepositoryTest.textIsFoundWithOrWithoutItsMarks`                                                |
| The last word is matched as the start of a word while it is typed                                                                                                                                                                                                                   | Nothing found until a word is complete                                           | `SearchDocumentRepositoryTest.theLastWordIsFoundWhileItIsTyped`                                                |
| A typo in a title is forgiven                                                                                                                                                                                                                                                       | "voise agent" finding nothing                                                    | `SearchDocumentRepositoryTest.aTypoInATitleIsForgiven`                                                         |
| A match in the title ranks above a match in the description                                                                                                                                                                                                                         | An item that only mentions the word above the one named for it                   | `SearchDocumentRepositoryTest.aTitleOutranksADescription`                                                      |
| An unlisted solution never reaches a visitor's results or counts, and stays available to matching                                                                                                                                                                                   | An unlisted solution shown publicly                                              | `SearchDocumentRepositoryTest.anUnlistedSolutionReachesMatchingButNoVisitor`                                   |
| Counts cover every kind whatever kind is shown; pages are cut by kind, limit and offset                                                                                                                                                                                             | A tab count that changes with the open tab                                       | `SearchDocumentRepositoryTest.countsCoverEveryKindWhateverKindIsShown`                                         |
| Saving again replaces the row only when something changed, the content hash only when the text did; removing takes the item out                                                                                                                                                     | Duplicate rows; embeddings recomputed for nothing                                | `SearchDocumentRepositoryTest.savingAgainReplacesTheRowOnlyWhenSomethingChangedAndItsHashOnlyWhenTheTextDid`   |
| Text that looks like query syntax is only text                                                                                                                                                                                                                                      | A query with `&`, `:*` or a quote failing as a database error                    | `SearchDocumentRepositoryTest.textThatLooksLikeQuerySyntaxIsOnlyText`                                          |
| A published program is found without a session, with its partner, type, phase and cover, and leaves the results once taken down                                                                                                                                                     | A draft found; a program still found after it was unpublished                    | `SearchTest.aPublishedProgramIsFoundAndLeavesTheResultsWhenTakenDown`                                          |
| Every delivery of a program change completes, leaving the event publication registry empty                                                                                                                                                                                          | A listener failing silently, its publication kept for ever                       | `SearchTest.aPublishedProgramIsFoundAndLeavesTheResultsWhenTakenDown`                                          |
| The repair indexes a published program whose change was never delivered and takes out a row whose program is gone                                                                                                                                                                   | The index drifting from the programs after a lost delivery                       | `SearchTest.theRepairPutsBackWhatAMissedDeliveryLeftOutAndTakesOutWhatIsGone`                                  |
| A query that is missing, blank or longer than 100 characters, an unknown kind and a page outside 1 to 50 are pointed at                                                                                                                                                             | A query of any length reaching the database                                      | `SearchTest.aQueryThatIsMissingOrTooLongOrAPageOutOfRangeIsAValidationProblem`                                 |
| An approved solution is found under its organization's name with its maturity, industries and focus areas as words; a renamed organization shows its new name; an unlisted solution stays in the index for matching but leaves a visitor's results; a rejected one leaves the index | A solution shown under an old name, or still public after its owners unlisted it | `SearchDirectoriesTest.anApprovedSolutionIsFoundUnderItsOrganizationAndLeavesTheResultsWhenUnlistedOrRejected` |
| An approved, listed talent profile is found with its headline, roles and availability, and leaves the index when its person unlists it                                                                                                                                              | A person still found after they asked to be hidden                               | `SearchDirectoriesTest.anApprovedListedProfileIsFoundAndLeavesTheResultsWhenUnlisted`                          |
| `search` is a closed module that depends on `organization`, `program`, `solution` and `talent`                                                                                                                                                                                      | A module reading the index tables, or `search` reading another module's tables   | `ModulithArchitectureTest`                                                                                     |
| The address is in the contract                                                                                                                                                                                                                                                      | A web client generated from a stale contract                                     | `OpenApiContractTest`                                                                                          |

Not covered by a test: the nightly schedule itself; the repair it runs is the one the test calls, and the same repair runs when the application starts.
