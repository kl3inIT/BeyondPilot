# Audit: verification matrix

Boundaries follow [conventions › Testing](../conventions.md#testing). Writing an event is a transaction with the change it records, so `AuditTrailTest` runs the application against PostgreSQL without HTTP. Reading is the filter chain, the controller and a keyset query, so `AuditLogTest` starts the full application and speaks real HTTP against PostgreSQL; only the SMTP server is replaced. The table cannot be emptied, so each reading test records under a marker of its own and searches by it. That the account commands record their events is covered in the [identity matrix](identity.md).

## Backend

| Contract                                                                                                          | Regression it catches                                                           | Test                                                            |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| An event keeps who did what to what, as they were named                                                           | An event that cannot be read after a rename                                     | `AuditTrailTest.anEventKeepsWhoDidWhatToWhatAsTheyWereNamed`    |
| An event of the server configuration has no actor                                                                 | A change nobody made attributed to somebody                                     | `AuditTrailTest.anEventOfTheServerConfigurationHasNoActor`      |
| A change that rolls back leaves no event                                                                          | A record of something that did not happen                                       | `AuditTrailTest.aChangeThatRollsBackLeavesNoEvent`              |
| Recording needs the transaction of the change                                                                     | An event written apart from its change                                          | `AuditTrailTest.recordingNeedsTheTransactionOfTheChange`        |
| An event can be neither changed nor removed                                                                       | A record someone can rewrite                                                    | `AuditTrailTest.anEventCanBeNeitherChangedNorRemoved`           |
| An action refuses a detail it did not declare                                                                     | A secret slipped into the record at one call site                               | `AuditTrailTest.anActionRefusesADetailItDidNotDeclare`          |
| Nobody but an operator reads the log: 401 without a session, a 403 problem for another account                    | An open audit log; the `operatorsOnly` bean renamed or missing                  | `AuditLogTest.nobodyButAnOperatorReadsTheLog`                   |
| An operator whose role is withdrawn stops reading at once                                                         | A role read from the session                                                    | `AuditLogTest.anOperatorWhoseRoleIsWithdrawnStopsReadingAtOnce` |
| An event carries its action by stored name, its actor or null, its resource and its details                       | A list the screen cannot draw; an action published by its Java name             | `AuditLogTest.anEventCarriesWhoDidWhatToWhat`                   |
| The log is narrowed by action, by time and by a search over the actor and the resource; `%` and `_` are literal   | A filter that is ignored; a search that treats input as a pattern               | `AuditLogTest.theLogIsNarrowedByActionTimeAndSearch`            |
| The log is walked towards the past and back by its cursors, each event once, and the first page has nothing newer | A page that repeats or skips events; a way back that lands on a different page  | `AuditLogTest.theLogIsWalkedTowardsThePastAndBackByItsCursors`  |
| A parameter that is not valid is a validation problem                                                             | A 500 for a cursor that is not one, an unknown action or a date that is not one | `AuditLogTest.aParameterThatIsNotValidIsAValidationProblem`     |

## Web

`web/tests/e2e/admin-audit-log.spec.ts`, on desktop and mobile Chrome with axe, the list answered by `tests/e2e/stub-backend.mjs`.

| Contract                                                                                                                                                        | Regression it catches                                                                | Test                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| A visitor is sent to sign in and back; an account that is not an operator gets the not-found page                                                               | A log that gives itself away                                                         | `nobody but an operator gets the log`                                              |
| The last seven days are shown newest first, each event as one sentence; an event of the configuration names "System"; a table from 768px and stacked rows below | A default period that hides or floods; an event without an actor that breaks the row | `an operator reads the last seven days, newest first, each event as one sentence`  |
| The short time carries the full date and time to the second                                                                                                     | A time that cannot be told exactly                                                   | `the short time carries the full date and time`                                    |
| Period, action and search are the address and survive a reload                                                                                                  | A filter kept in the browser only                                                    | `period, action and search are the address, and the server answers them`           |
| A log longer than a page is walked towards the past and back, keeping the search; a way that does not exist is not offered                                      | Paging that drops the filters or dead-ends                                           | `a log longer than a page is walked towards the past and back, keeping the search` |
| A cursor that is not one leads to the newest events, keeping the filters                                                                                        | A failure page for a hand-edited address                                             | `a cursor that is not one leads to the newest events`                              |
| A search that finds nothing says so and offers the way back                                                                                                     | An empty table without a word                                                        | `a search that finds nothing says so and offers the way back`                      |
| The sidebar leads to the audit log and marks it current                                                                                                         | A screen nobody can reach                                                            | `the sidebar leads to the audit log and marks it as the current page`              |
