## Web

`web/tests/e2e/mcp.spec.ts`, with axe, the backend answered by `tests/e2e/stub-backend.mjs`.

| Contract                                                                                                                               | Regression it catches                                                | Test                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| A visitor to `/account/mcp` is sent to sign in; someone who is not an operator gets the not-found page for `/admin/ai/mcp`             | The page or the admin giving itself away                             | `a visitor is sent to sign in`, `someone who is not an operator is not shown the MCP admin`    |
| A person finds the server's address and each app's steps, sees their connected apps and revokes one after confirming, with one request | A person who cannot connect an app, or cannot end a connection       | `a person finds the server's address, the steps and their apps, and revokes one`               |
| With no app connected, the list leads back to connecting one; the account menu leads to the page                                       | A dead end; a page nobody reaches                                    | `with no app connected, the list leads back to connecting one`, `the account menu leads to it` |
| An operator finds the operators' server address, adds a trusted host, switches a tool on, and is asked first before switching one off  | A switch that acts unasked; a host that is not sent                  | `an operator finds the operators' server, switches a tool and trusts a host`                   |
| An operator sees every person's connected apps and revokes one, and narrows the calls by outcome in the address                        | Connections an operator cannot end; activity that ignores its filter | `an operator sees every connected app and revokes one, and reads the calls by filter`          |
