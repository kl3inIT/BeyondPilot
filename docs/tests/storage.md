# Storage: verification matrix

Boundaries follow [conventions › Testing](../conventions.md#testing). An upload is three HTTP requests, a database row and an object in a store, so the tests start the full application against PostgreSQL and speak real HTTP. `LocalStorageTest` runs the local object store on a temporary directory. `S3StorageTest` runs the S3 adapter against MinIO in a container, and plays the browser itself: it sends the bytes to the presigned address, so they never reach the application. Sign-in goes through the real code flow with the SMTP server replaced.

| Contract                                                                                                                                                                                            | Regression it catches                                                                                                   | Test                                                                                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| An operator reserves, sends and confirms an image; anyone reads it without a session, and may cache it for good                                                                                     | An upload that does not end in a readable file; a public image behind a session; an image that is fetched on every view | `LocalStorageTest.anOperatorUploadsAnImageInThreeRequestsAndAnyoneReadsIt`                                                             |
| The name a person gave is kept without the directory in front of it                                                                                                                                 | A stored Windows or Unix path shown or downloaded as a file name                                                        | Same test (`C:\covers\cover.png` becomes `cover.png`)                                                                                  |
| A purpose refuses a media type it does not list, a size over its limit, a caller who may not use it, an unknown purpose, an empty file and a caller without a session                               | SVG or another scriptable type accepted as an image; a file over the limit; an applicant uploading a program's image    | `LocalStorageTest.aPurposeRefusesWhatItDoesNotAccept`                                                                                  |
| A file is stored only when its bytes are in the store, have the announced length and start as its media type does; a refused upload is removed                                                      | Confirming a file nobody uploaded; a PNG kept as a PDF                                                                  | `LocalStorageTest.aFileIsNotStoredUntilItsBytesAreTheAnnouncedFile`, `S3StorageTest.theBucketRefusesBytesThatAreNotTheAnnouncedFile`   |
| A use case attachment is taken by what its bytes are: Office files of both generations, CSV (also as Windows announces it) and text; a picture named a Word file and a binary named CSV are refused | Office files refused; a disguised file accepted                                                                         | `aUseCaseAttachmentIsTakenByWhatItsBytesAre`                                                                                           |
| An upload never confirmed is removed a day after its time ran out; a recent one and a stored file stay                                                                                              | Abandoned uploads piling up; a stored file removed                                                                      | `anUploadNeverConfirmedIsRemovedADayAfterItsTimeRanOut`                                                                                |
| The local ticket works once, only for its owner, only with the CSRF header, only for the announced length and only until it expires                                                                 | A reusable or guessable upload address; writing into another person's pending file; a body longer than announced        | `LocalStorageTest.aTicketWorksOnceForItsOwnerAndForTheAnnouncedLength`                                                                 |
| The public address answers `404` for a private file and for a pending one                                                                                                                           | A deck readable by anyone who has its identifier; a file read before it is confirmed                                    | `LocalStorageTest.aPrivateOrPendingFileIsNotServedByThePublicAddress`, `S3StorageTest.theBucketRefusesBytesThatAreNotTheAnnouncedFile` |
| An owning module gets a file only when it is stored, has the purpose it expects and was uploaded by the caller; it reads a private file as a download and can delete it                             | Attaching someone else's file, or a file of another kind, to a record; a deleted file whose bytes stay                  | `LocalStorageTest.aPrivateOrPendingFileIsNotServedByThePublicAddress`                                                                  |
| With S3 the ticket is a presigned address of the bucket, and the public read is a redirect to one that serves the image inline                                                                      | Bytes routed through the application on AWS; an image offered as a download                                             | `S3StorageTest.theBrowserSendsAnImageStraightToTheBucketAndReadsItThroughARedirect`                                                    |
| The bucket itself refuses a body longer than was signed, and another media type than was signed                                                                                                     | A presigned address that accepts any file                                                                               | `S3StorageTest.theBucketRefusesBytesThatAreNotTheAnnouncedFile`                                                                        |
| A private file on S3 is read through an address that downloads it under its name, and stops working when the file is deleted                                                                        | A deck shown inline under a generated key; bytes left in the bucket                                                     | Same test                                                                                                                              |
| `storage` is a closed module that depends on `identity` only                                                                                                                                        | A module reaching into storage's adapters or tables, or storage reaching into a module that owns files                  | `ModulithArchitectureTest`                                                                                                             |
| The four addresses are in the contract                                                                                                                                                              | A web client generated from a stale contract                                                                            | `OpenApiContractTest`                                                                                                                  |

Not covered by a test, and checked by hand on the first AWS environment: an upload from a real browser to a real bucket, which is what proves the bucket's CORS rules and the role's permissions.

The MinIO image is Chainguard's build, pinned by digest in `S3StorageTest`: MinIO no longer publishes an image of its own.
