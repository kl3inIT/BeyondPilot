# Program: verification matrix

Boundaries follow [conventions › Testing](../conventions.md#testing). An operator's change is an HTTP request, a row, its lists and an audit event, and a visitor's read depends on the session and the clock, so the program tests start the full application against PostgreSQL and speak real HTTP. Sign-in goes through the real code flow with the SMTP server replaced. Where a program stands is a function of its dates and a moment, so its boundaries are a unit test.

| Contract                                                                                                                                                                   | Regression it catches                                                                            | Test                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Only an operator lists, reads, creates, saves, publishes and unpublishes programs; a caller without a session is refused before any of it                                  | A user editing or publishing a program; an operator's address reachable without a session        | `ProgramAdministrationTest.nobodyButAnOperatorReadsOrCreatesPrograms`                                                                                                               |
| A program starts as a draft with what it was created with, is listed newest first and records its creation                                                                 | A program public from the start; a creation without an audit event                               | `ProgramAdministrationTest.anOperatorCreatesADraftAndReadsItBack`, `theListIsNewestFirst`                                                                                           |
| An address belongs to one program and has the form of an address                                                                                                           | Two pages at one address; an address with spaces or capitals                                     | `ProgramAdministrationTest.anAddressBelongsToOneProgram`, `aRequestThatIsNotValidPointsAtItsMembers`                                                                                |
| A save keeps everything the Settings screen holds and replaces the lists and the window as sent                                                                            | A key date lost or kept after it was removed; a window kept after applications were switched off | `ProgramAdministrationTest.aSaveKeepsEverythingTheScreenHolds`, `aSaveReplacesTheListsAndTheWindowAsSent`                                                                           |
| A save over someone else's save is refused                                                                                                                                 | The second operator silently overwriting the first                                               | `ProgramAdministrationTest.aSaveOverSomeoneElsesSaveIsRefused`                                                                                                                      |
| Days, the window, outcomes, key dates and events out of order, and an outside page without its address, are refused with their own codes; a malformed member is pointed at | A deadline before the opening; outcomes due before the deadline                                  | `ProgramAdministrationTest.datesOutOfOrderAreRefused`, `aSavedMemberThatIsNotValidIsPointedAt`                                                                                      |
| The address changes until the first publication and is fixed from then on                                                                                                  | A shared link that stops working                                                                 | `ProgramAdministrationTest.anAddressChangesUntilTheFirstPublication`, `aProgramIsPublishedOnceItHasWhatTheListShowsAndUnpublishedAtWill`                                            |
| A cover is a stored image the caller uploaded and no other program's; a replaced cover is removed after the save                                                           | Another person's file, a pending file or a deck as a cover; replaced covers kept for ever        | `ProgramAdministrationTest.aCoverIsAStoredImageOfTheCallerAndAReplacedOneIsRemoved`                                                                                                 |
| Publishing needs a summary, a cover and the days, listed as `publishIssues`; publishing and unpublishing are recorded once each, and unpublishing keeps the address        | A program on the list without what the list shows; a repeated command recorded twice             | `ProgramAdministrationTest.aProgramIsPublishedOnceItHasWhatTheListShowsAndUnpublishedAtWill`                                                                                        |
| A program is upcoming, open, running or done at each boundary of its dates, in Vietnam time                                                                                | A program shown as open after its deadline, or done on its last day                              | `ProgramPhaseTest`                                                                                                                                                                  |
| The public list holds published programs only, each in its phase, narrowed by phase and type, with its window and its next three events                                    | A draft on the public list; a past event shown as coming up                                      | `ProgramPublicTest.theListHoldsPublishedProgramsOnlyEachInThePhaseItIsInNow`, `aProgramOnTheListCarriesItsWindowAndItsNextThreeEvents`, `aParameterOutOfBoundsIsAValidationProblem` |
| A program's page carries its text, window, key dates and events without a session                                                                                          | A page that needs a sign-in                                                                      | `ProgramPublicTest.aPublishedProgramsPageCarriesWhatItShows`                                                                                                                        |
| A draft's page is found by an operator only; a visitor and a user get `404`, as for an unknown address                                                                     | A draft readable by anyone who guesses its address                                               | `ProgramPublicTest.aDraftIsFoundByAnOperatorOnly`, `anUnknownAddressIsNotFound`                                                                                                     |
| `program` is a closed module that depends on `audit`, `identity` and `storage`                                                                                             | A module reaching into the program tables                                                        | `ModulithArchitectureTest`                                                                                                                                                          |
| The addresses are in the contract                                                                                                                                          | A web client generated from a stale contract                                                     | `OpenApiContractTest`                                                                                                                                                               |

Not covered by a test: two saves that take the same address or cover at the same moment. The unique constraints decide, and the failure is mapped by the constraint's name.
