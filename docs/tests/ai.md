# AI: verification matrix

Boundaries follow [conventions › Testing](../conventions.md#testing). What the module promises is what an operator can do over HTTP and what a provider is sent, so `AiAdministrationTest` starts the full application against PostgreSQL, signs in through the real code flow and speaks real HTTP. The provider is the JDK's `HttpServer`, as MemoryOS tests its adapter: it answers as OpenAI, 9Router, OpenRouter and Anthropic do, and keeps what it was asked. No test calls a real provider. `ModelClientsTest` holds the leased cache alone, without Spring, because who gets which client and when one is closed is a matter of order that HTTP cannot pin.

| Contract | Regression it catches | Test |
| --- | --- | --- |
| Only operators read or change the chat settings, list a provider's models or try a model | A member connecting a provider or spending tokens | `AiAdministrationTest.onlyOperatorsSeeOrChangeTheChatSettings` |
| A chat provider takes an `http` or `https` address, private hosts included, and refuses one with credentials, a query or a fragment; its key is sealed and never returned, in the API, the database or the audit record | A self-hosted gateway refused; a key in a response, in clear in a row, or in the audit trail | `aChatProviderTakesAnyHttpAddressAndItsKeyNeverComesOut` |
| A provider test lists the models and names a refused key, an unreachable provider and an answer that is not the API's; the provider's text never comes back; a redirect is not followed | A provider's error shown to the operator; a key sent on to another host | `aTestListsTheModelsAndNamesTheFailureWithoutTheProvidersWords` |
| Listing reads each provider's own fields and the catalog fills what it leaves out; an unknown price stays unknown; a listing that fails answers the problem of its kind | A price or a limit guessed; a provider's own values overwritten by the catalog's | `modelsComeFromTheProviderAndTheCatalogFillsWhatItLeavesOut` |
| Claude is listed through Anthropic's own API, with `x-api-key` and the version header, whether or not the address ends in `/v1` | The Anthropic adapter asking as OpenAI does | `claudeIsListedThroughAnthropicsOwnApi` |
| A saved key is used only for the address it was saved with, in a test and in a change | An operator pointing a provider at their own server to receive the key | `aSavedKeyIsUsedOnlyForTheAddressItWasGivenFor` |
| A task takes a model only of a switched-on provider with a key; a stale choice is refused; removing the model or its provider unsets the task; each change is audited | A task left on a model that is gone; two operators overwriting each other | `aTaskUsesAModelOfASwitchedOnProviderAndIsUnsetWhenTheModelGoes` |
| A task without a model does not run | A call falling back to a model nobody chose | `aTaskWithoutAModelDoesNotRun` |
| A call reaches the provider with the key, the model and the task's reasoning level, and leaves one usage row with its tokens, what it was about and the prices then; nothing asked or answered is kept; a later price change does not rewrite it | Calls that are not recorded; a prompt in the usage table; past cost changing with today's price | `everyCallIsRecordedWithItsTokensAndThePriceThen` |
| A call that fails leaves one row with the kind of failure and none of the provider's text | Failed calls missing from the record; a provider's message stored | `aCallThatFailsIsRecordedWithoutTheProvidersWords` |
| An operator tries a model: it is asked without a reasoning level and the call is recorded as `model_test`; a model that does not answer fails the test without the provider's text | A test that spends tokens off the record; a provider's error shown to the operator | `anOperatorTriesAModelAndTheCallIsRecordedAsATest`, `aModelThatDoesNotAnswerFailsItsTestWithoutTheProvidersWords` |
| A changed key serves the next call while a call in flight keeps its client | An answer cut by an operator's change; a call still sent with the old key after it | `aChangedKeyServesTheNextCallWhileACallInFlightKeepsItsClient` |
| Calls of one key share a client until its revision changes; the old client closes when its last call returns, and closing a lease twice gives back once | A client per call; a client closed under a running call; a count driven below zero | `ModelClientsTest.callsOfOneKeyShareAClientUntilItsRevisionChanges` |
| A full cache gives up an idle client and refuses when every one is in use | Clients without bound; a busy client closed to make room | `ModelClientsTest.aFullCacheGivesUpAnIdleClientAndRefusesWhenEveryOneIsInUse` |
| A client that cannot be built leaves no slot taken | A failed connection that fills the cache | `ModelClientsTest.aClientThatCannotBeBuiltLeavesNoSlotTaken` |
| Shutting down closes idle clients and leaves one in use to its call | A call cut at shutdown; a client never closed | `ModelClientsTest.shuttingDownClosesIdleClientsAndLeavesOneInUseToItsCall` |
| The provider `search` embeds with cannot be removed, and search behaves as before the move | The move to `ai` changing what Admin › AI › Embedding does | `SearchAdministrationTest`, `SearchMeaningTest` ([search matrix](search.md)) |
| `ai` is a closed module that depends on `audit` and `identity` only | `ai` reaching into a module that calls it; a module reading its tables | `ModulithArchitectureTest` |
| The chat endpoints are in the contract | A web client generated from a stale contract | `OpenApiContractTest` |

Not covered by a test, and checked by hand on staging: a call to the real OpenAI, Anthropic and 9Router APIs, which is what proves the reasoning level and the thinking budget are accepted by the models chosen.
