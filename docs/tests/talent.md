# Talent: verification matrix

Boundaries follow [conventions › Testing](../conventions.md#testing). `TalentTest` starts the full application against PostgreSQL and speaks real HTTP, signing in through the emailed code as the identity tests do; only the SMTP server is replaced, which is how it reads the email an enquiry sends.

| Contract                                                                                                                                                                                                | Regression it catches                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| A person has one profile; the first save creates it, later saves need its `version`                                                                                                                     | Two profiles for one account; a stale tab overwriting a save             |
| A submission needs a headline, a bio, a role and a skill                                                                                                                                                | An empty profile in the directory                                        |
| An operator approves a profile in review, or sends it back with a reason (`needs_changes`); the person is emailed and can send it again                                                              | A decision without a way back, or one the person never hears of          |
| An operator takes an approved profile down, never one that waits; its review stays `approved` with `suspendedAt` set, its public page answers `404`, the operators' list finds it under `suspended`, and Restore puts it back without a new review | A profile GenAI Fund cannot take down, or one it cannot put back |
| A person corrects a profile taken down and sends it again; approving it lifts the takedown                                                                                                                | A takedown with no way back for the person                               |
| A person deletes their profile with its messages, and the audit log keeps it                                                                                                                            | Personal data that cannot be taken back                                  |
| Only operators read the reported messages, with the sender's address                                                                                                                                    | A report nobody reads                                                    |
| The directory shows only approved and listed profiles, filtered by search, role, country and engagement                                                                                                 | A draft or a hidden profile shown to the public                          |
| A public profile never carries the person's email address                                                                                                                                               | Addresses harvested from the directory                                   |
| An enquiry needs a session and a topic, is refused on one's own profile, and one per sender and profile waits at a time                                                                                 | Anonymous or repeated messages to a person                               |
| The person is emailed who wrote, from which organization and about what, without the sender's address; they read the enquiry with no address until they accept                                          | An address shared before the person agreed                               |
| An acceptance emails each side the other's address; an enquiry answered once cannot be answered again, and only the person it was sent to answers it                                                    | A message that reaches nobody; an answer by someone else                 |
| A decline and a report send the sender the same email, with no address, and a report is audited                                                                                                         | A sender who learns they were reported                                   |
| A sender starts at most ten conversations a day                                                                                                                                                         | A sender writing to the whole directory                                  |
| A waiting enquiry reminds the person once after seven days and closes after fourteen, telling the sender, who may write again                                                                           | A message that waits forever, or a reminder every hour                   |
| Each approval, send back, takedown and restore is in the audit log                                                                                                                                                         | A decision nobody can trace                                              |
| The response to a submission carries the version the next save sends                                                                                                                                    | A save right after a submission refused as stale                         |
| The directory lists by name, or the most recently approved profiles first when asked                                                                                                                    | An order the visitor chose and did not get                               |
| A profile states its city, languages, industries, workplace and the stage of each project; the public page leaves the rate out                                                                          | A rate or a fact shown where it should not be                            |
| The directory narrows by country and by engagement, and each entry carries its first project and how many it shows                                                                                      | A filter the visitor chose and did not get                               |
| An enquiry is signed with the name the sender gives, and that name is what the person reads                                                                                                             | A message from "someone" whose acceptance hands an address to a stranger |
| The directory narrows by industry, and search finds a project title                                                                                                                                     | A buyer who cannot find people by the industry they come from            |
| A photo must be a stored upload of the caller for a talent profile                                                                                                                                      | Another person's file shown as one's photo                               |
| A save, an approval, a send back, a takedown, a restore and a deletion publish `TalentProfileChanged`, after which search finds an approved, listed profile that is not taken down and drops any other (`SearchDirectoriesTest`) | A person found by search after they asked to be hidden or were taken down |
