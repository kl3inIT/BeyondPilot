# Talent: verification matrix

Boundaries follow [conventions › Testing](../conventions.md#testing). `TalentTest` starts the full application against PostgreSQL and speaks real HTTP, signing in through the emailed code as the identity tests do; only the SMTP server is replaced, which is how it reads the email a decision sends. The messages people write through a profile are conversations of the `messaging` module, and are verified there.

| Contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Regression it catches                                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A person has one profile; the first save creates it, later saves need its `version`                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Two profiles for one account; a stale tab overwriting a save                                                                                                    |
| A submission needs a headline, a bio, a role and a skill                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | An empty profile in the directory                                                                                                                               |
| An operator approves a profile in review, or sends it back with a reason (`needs_changes`); the person is emailed, with a link to the public profile or to their own to correct, and can send it again                                                                                                                                                                                                                                                                                                                                                       | A decision without a way back, or one the person never hears of                                                                                                 |
| An operator takes an approved profile down, never one that waits; its review stays `approved` with `suspendedAt` set, its public page answers `404`, the operators' list finds it under `suspended`, and Restore puts it back without a new review                                                                                                                                                                                                                                                                                                           | A profile GenAI Fund cannot take down, or one it cannot put back                                                                                                |
| The operators' list sorts by `name` or `submitted`, `-` turning it round and one never sent last either way; no `sort` keeps those waiting first, the longest wait on top, and an unknown key answers `400`                                                                                                                                                                                                                                                                                                                                                  | A header that sorts nothing; pages that overlap; a key concatenated into SQL                                                                                    |
| A person corrects a profile taken down and sends it again; approving it lifts the takedown                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | A takedown with no way back for the person                                                                                                                      |
| A person deletes their profile with the conversations started through it, and the audit log keeps it (`TalentTest.aPersonDeletesTheirProfileWithTheConversationsStartedThroughIt`)                                                                                                                                                                                                                                                                                                                                                                           | Personal data that cannot be taken back; a deletion refused because a conversation still names the profile                                                      |
| The directory shows only approved and listed profiles, filtered by search, role, country and engagement                                                                                                                                                                                                                                                                                                                                                                                                                                                      | A draft or a hidden profile shown to the public                                                                                                                 |
| A public profile never carries the person's email address                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Addresses harvested from the directory                                                                                                                          |
| Each approval, send back, takedown and restore is in the audit log                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | A decision nobody can trace                                                                                                                                     |
| The response to a submission carries the version the next save sends                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | A save right after a submission refused as stale                                                                                                                |
| The directory lists by name, or the most recently approved profiles first when asked                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | An order the visitor chose and did not get                                                                                                                      |
| A profile states its city, languages, industries, workplace and the stage of each project; the public page leaves the rate out                                                                                                                                                                                                                                                                                                                                                                                                                               | A rate or a fact shown where it should not be                                                                                                                   |
| The directory narrows by country and by engagement, and each entry carries its first project and how many it shows                                                                                                                                                                                                                                                                                                                                                                                                                                           | A filter the visitor chose and did not get                                                                                                                      |
| The directory narrows by industry, and search finds a project title                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | A buyer who cannot find people by the industry they come from                                                                                                   |
| A photo must be a stored upload of the caller for a talent profile                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Another person's file shown as one's photo                                                                                                                      |
| A save, an approval, a send back, a takedown, a restore and a deletion publish `TalentProfileChanged`, after which search finds an approved, listed profile that is not taken down and drops any other (`SearchDirectoriesTest`)                                                                                                                                                                                                                                                                                                                             | A person found by search after they asked to be hidden or were taken down                                                                                       |
| Featured profiles come first only in the view the directory opens with: no search, no filter, the newest first, the earliest featured on top; they are counted once and do not come again on a later page. A search, any filter or another order is ordered by that alone, exactly as before anything was featured. No public card marks a featured profile (`TalentTest.featuredProfilesLeadOnlyTheViewTheDirectoryOpensWith`)                                                                                                                              | A featured profile pushed above what the reader searched, filtered or sorted for; one repeated on the second page or counted twice; a public card that marks it |
| Only an operator features a profile and stops, any profile that was sent for review and never a draft; featuring twice keeps the first time; each change is in the audit log once; a profile stays featured through a save of its person, which is not refused as stale for it, and through a takedown and a restore; one featured before it is public is shown as featured once it is; the operators' list carries `featuredAt` and narrows by `featured` (`TalentTest.onlyAnOperatorFeaturesAProfileWhichStaysFeaturedThroughWhatItsPersonAndGenAiFundDo`) | Its person featuring their own profile; a save that drops it or is refused because of it; a change nobody can trace                                             |
