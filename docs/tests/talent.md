# Talent: verification matrix

Boundaries follow [conventions › Testing](../conventions.md#testing). `TalentTest` starts the full application against PostgreSQL and speaks real HTTP, signing in through the emailed code as the identity tests do; only the SMTP server is replaced, which is how it reads the email an enquiry sends.

| Contract                                                                                                                                                                                                                                   | Regression it catches                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| A person has one profile; the first save creates it, later saves need its `version`                                                                                                                                                        | Two profiles for one account; a stale tab overwriting a save |
| A submission needs a headline, a bio, a role and a skill                                                                                                                                                                                   | An empty profile in the directory                            |
| An operator approves a submitted profile, or rejects it with a reason; a rejected one can be sent again                                                                                                                                    | A rejection without a way back                               |
| An operator takes an approved profile down, and its public page answers `404`                                                                                                                                                              | A profile GenAI Fund cannot remove                           |
| The directory shows only approved and listed profiles, filtered by search, role and availability                                                                                                                                           | A draft or a hidden profile shown to the public              |
| A public profile never carries the person's email address                                                                                                                                                                                  | Addresses harvested from the directory                       |
| An enquiry needs a session, is refused on one's own profile, and is taken once per sender, profile and day                                                                                                                                 | Anonymous or repeated messages to a person                   |
| The person reads their enquiries with the sender's name and address; the message is also emailed                                                                                                                                           | A message that reaches nobody                                |
| Each approval and rejection is in the audit log                                                                                                                                                                                            | A decision nobody can trace                                  |
| The response to a submission carries the version the next save sends                                                                                                                                                                       | A save right after a submission refused as stale             |
| The directory lists by name, or the most recently approved profiles first when asked                                                                                                                                                       | An order the visitor chose and did not get                   |
| A save, an approval and a rejection publish `TalentProfileChanged`, after which search finds an approved, listed profile and drops an unlisted one (`SearchDirectoriesTest.anApprovedListedProfileIsFoundAndLeavesTheResultsWhenUnlisted`) | A person found by search after they asked to be hidden       |
