# BEY-96 — Operators download a list as a spreadsheet

Status: decisions taken by Đạt on 14 October 2026 ([plan](plan.md)); being built.

## Why

Brief §7.10 asks to "export operational data and report useful campaign/application counts". Today two lists can be downloaded, both in `proposal` and both as CSV that `ReviewService` writes by hand through `CsvRows`: a program's applications (BEY-77) and its drafts (BEY-193). Every other list an operator works with in Admin has no download, and the CSV opens in Excel as plain text: no header that stays in view, no filters, times as text in UTC, scores as text.

GenAI Fund works in Excel (the old platform's full export they shared on 12 October 2026 is a workbook), so the download should open as a readable workbook, and the same columns should be one declaration whatever the list.

## Domain story

1. Minh, an operator of GenAI Fund, narrows Admin › Organizations to Vietnamese companies waiting for review.
2. He opens **Export** in the page's actions and chooses **Excel (.xlsx)**.
3. His browser saves `organizations-2026-10-14.xlsx`. It opens on a sheet whose bold header stays in view, with a filter on every column, dates he can sort, and a second sheet, About, that says which list it is, the filters he set, how many rows, that he downloaded it and when.
4. Later he chooses **CSV** on the same list to load it into another tool. The file holds the same columns, one header row.
5. The audit log shows that Minh downloaded the organizations, and how many.

Failure paths: a person who is not an operator asks for a download (refused, nothing recorded); the list matches nothing (a file with its header and no rows); the list matches more rows than a download holds (refused with a code that says so, nothing recorded).

## How others do it

Studied on 14 October 2026; the comparison is in [BEY-96](https://linear.app/beyondpilot/issue/BEY-96).

| Reference                                                                   | How                                                                                                                                                                 |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Jmix, Grid Export Actions (`ExcelExportAction`)                             | One action on any grid: the grid's columns and captions, all rows or the selected or the current page, written with Apache POI; column widths from the values       |
| Dub (`.tmp/dub/apps/web`, `api/partners/applications/export/route.ts`)      | The columns of each kind declared once (`exportApplicationColumns`), one `convertToCSV` that neutralizes formulas (`neutralizeCsvFormula`), a modal to pick columns |
| Medusa (`.tmp/medusa`, `routes/products/product-export/product-export.tsx`) | The export takes the list's current filters; a background workflow and a notification with the file                                                                 |

All three write on the server. BeyondPilot does too: the lists are paged, the files hold contact details only operators read, and each download is recorded.

## Decisions

| Decision                                                                                                                                                                                                                                                                            | Why                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Only operators download, and every download is recorded in the audit log with how many rows it holds                                                                                                                                                                                | Decided by Đạt. A download takes data out of BeyondPilot, contact details among it                                                                                                                                                                                                                                       |
| Both XLSX and CSV; the page's **Export** menu offers both                                                                                                                                                                                                                           | Decided by Đạt: the workbook to read, CSV for another tool                                                                                                                                                                                                                                                               |
| Headers in English, whatever the language of the screen                                                                                                                                                                                                                             | Decided by Đạt; English is the default language ([BEY-98](https://linear.app/beyondpilot/issue/BEY-98))                                                                                                                                                                                                                  |
| Apache Fesod (`org.apache.fesod:fesod-sheet` 2.1.0-incubating) writes both formats                                                                                                                                                                                                  | Probed on Java 25.0.2 and Spring Boot 4.1.1 (`.tmp/fesod-probe`): two-level headers, real date cells, CSV with a byte order mark, 200,000 rows in a 256 MB heap in 3.8 s, no dependency clash. It also reads, for the import BEY-96 tracks later, and fills templates (BEY-194). Incubating: only `Spreadsheet` calls it |
| A new module, `shared`, holds `Spreadsheet`, `SpreadsheetFormat`, `SpreadsheetFile` and `SPREADSHEET_TOO_LARGE`; it depends on no module, and the modules that download declare it ([ADR 0009](../../decisions/0009-a-shared-module-writes-the-spreadsheets-operators-download.md)) | The [backend guide](../../../guidelines/backend.md#where-things-live) keeps `shared` for technical utilities that at least two modules need and that know nothing about a module; seven modules write a spreadsheet                                                                                                      |
| Columns are declared on `Spreadsheet`, by kind (text, paragraph, label, count, decimal, dollars, time, day, yes/no, email, link), and rows are any record                                                                                                                           | The probe found that Fesod writes a record as an empty row without an error and cannot read one. Writing cells from declared columns keeps DTOs as records and leaves no annotation of Fesod in a module                                                                                                                 |
| The workbook: a bold header on a grey band that stays in view, a filter on every column, widths from the values, times as dates in Vietnam time, figures as numbers, addresses that open, and an About sheet                                                                        | What makes the file read well in Excel; Jmix computes widths the same way. An address opens only when it is `http`, `https` or an email, so `javascript:` typed by someone stays text                                                                                                                                    |
| In CSV a cell that a spreadsheet would run as a formula starts with `'`, except a phone number or a figure                                                                                                                                                                          | `CsvRows`' rule, carried over. In a workbook every text is a text cell, which never runs                                                                                                                                                                                                                                 |
| A download is the list as the screen narrows it, every page of it: the export endpoint takes the list's own request without the page                                                                                                                                                | What the operator sees is what they get, as Medusa does. The service reads the list a page of 100 at a time through the same method, so the filters, the order and the authorization are the list's own                                                                                                                  |
| At most 10,000 rows; beyond, `SPREADSHEET_TOO_LARGE`, nothing written or recorded                                                                                                                                                                                                   | Bounded memory. The largest list today, organizations, holds about 2,400                                                                                                                                                                                                                                                 |
| `POST …/export?format=xlsx\|csv`, the list's filters in the query                                                                                                                                                                                                                   | A download is recorded, so it is not a `GET`; the two existing exports are already `POST`                                                                                                                                                                                                                                |
| A program's applications keep their own request, the identifiers the list shows                                                                                                                                                                                                     | Their filters run in the browser (`review-search.ts`), so the server cannot rebuild them                                                                                                                                                                                                                                 |
| The audit log is downloaded through `identity`, at `POST /api/identity/admin/audit-events/export`                                                                                                                                                                                   | `audit` cannot name the caller ([ADR 0004](../../decisions/0004-the-filter-chain-keeps-the-audit-log-for-operators.md)), so it could not record who downloaded it. `identity` already depends on `audit`, checks the operator and records                                                                                |
| The file is named after the list and the day in Vietnam time: `organizations-2026-10-14.xlsx`, `tasco-applications-2026-10-14.csv`                                                                                                                                                  | Several downloads of one list sort by day                                                                                                                                                                                                                                                                                |
| Accounts, email and MCP have no download                                                                                                                                                                                                                                            | Nobody takes them out of BeyondPilot; accounts are personal data with no use outside                                                                                                                                                                                                                                     |

## What changes

- **Backend.** The module `shared` and `ModulithArchitectureTest`; `fesod-sheet` in the version catalog. In each module of the table, an `export` beside its list in the application service and the controller, its audit action and its tests; `proposal` loses `CsvRows`, `ApplicationsCsv` and `CsvRowsTest` for `Spreadsheet`. `SPREADSHEET_TOO_LARGE` is `shared`'s own failure. `openapi.yml` and the generated web client. [ADR 0009](../../decisions/0009-a-shared-module-writes-the-spreadsheets-operators-download.md) records the new module.
- **Web.** An `ExportMenu` composite: one **Export** button that opens Excel (.xlsx) and CSV and saves the file the server names. It replaces `export-applications.tsx` and `export-drafts.tsx`, and joins the header actions of the other lists. The audit log's new actions, both catalogs, the stub backend and the Playwright specs.
- **Documents.** `ARCHITECTURE.md` (the module), the specs and test matrices of the modules, `docs/specs/audit.md`, the roadmap.
